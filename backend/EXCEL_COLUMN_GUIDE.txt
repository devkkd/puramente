❓ अगर Meta columns अभी भी नहीं दिख रहे:

Option 1: Right-arrow key press करो
   → Excel में सभी columns को right scroll करने से सब दिखेगा

Option 2: Column J पर click करो
   → फिर Shift+Right arrow press करके columns को select करो
   → सब दिखने लगेंगे

Option 3: Format → Column → Unhide select करो
   → अगर columns hidden हों

अगर आपका पुराना Excel template है और Meta columns नहीं हैं, तो:

STEP 1: अपने Excel में सबसे आखिरी column के बाद नया column add करो
────────────────────────────────────────────────────────────────
   ✅ Best Seller के बाद right-click करो (Column I के बाद)
   ✅ Insert → Columns Right चुनो
   ✅ नया empty column आ जाएगा (अब यह Column J है)

STEP 2: Column Headers add करो (सबसे पहली row में)
────────────────────────────────────────────────────────
   Column J  = "Meta Title"
   Column K  = "Meta Description"  
   Column L  = "Meta Keyword 1"
   Column M  = "Meta Keyword 2"
   Column N  = "Meta Keyword 3"

STEP 3: Columns के width बढ़ाओ (ताकि data दिखे)
────────────────────────────────────────────────
   ✅ Column J header पर double-click करो (auto-fit हो जाएगा)
   ✅ Column K, L, M, N पर भी double-click करो

STEP 4: अपने products के साथ fill करो
────────────────────────────────────────
   Example:
   Row 1 (Header): Meta Title | Meta Description | Meta Keyword 1 | ...
   Row 2 (Data):   Classic Pearl Necklace | Discover our... | pearl necklace | ...

STEP 5: Save करो as Excel file (.xlsx)
─────────────────────────────────────────
   Ctrl+S → Save As → Format: Excel Workbook (.xlsx)

WHAT WAS FIXED

OLD CODE (rigid, fails on variations):
  const optionEnum = subCat.toLowerCase() === "with gemstone" ? "with gem" : "without gem";

NEW CODE (flexible, handles all cases):
  const normalizedSubCat = subCat.toLowerCase().trim();
  if (normalizedSubCat.includes("without") || normalizedSubCat === "no gem" || normalizedSubCat === "") {
    optionEnum = "without gem";
  } else if (normalizedSubCat.includes("gem")) {
    optionEnum = "with gem";
  } else if (normalizedSubCat !== "") {
    console.warn(\⚠️ Row \: Sub-Category unrecognized...\);
  }
